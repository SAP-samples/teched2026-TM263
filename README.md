# TM263 - AI-accelerated RISE with SAP migration with the system transition workbench
[![REUSE status](https://api.reuse.software/badge/github.com/SAP-samples/teched2026-TM263)](https://api.reuse.software/info/github.com/SAP-samples/teched2026-TM263)

## Overview
<p align="justify">This hands-on session shows how to perform a <b>homogeneous SAP S/4HANA migration</b> to <b>RISE with SAP</b> using the <b>RISE with SAP System Transition Workbench</b>. You will perform a guided <b>lift-and-shift sandbox migration</b> of an <b>SAP S/4HANA FOUNDATION 2025 FPS01</b> system to the <b>Private Cloud Environment</b>, with <b>SAP HANA tenant replication</b> as the technical migration approach.</p><br>

![](./exercises/ex0/images/Screenshot-1-01.png)<br><br>

<p align="justify">Using the <b>RISE with SAP System Transition Workbench</b>, you will <b>check migration prerequisites</b>, <b>prepare the required software</b>, and <b>establish SAP HANA replication</b> before completing <b>downtime processing</b>, <b>post-processing</b>, and the <b>final application switchover</b>. Along the way, you will document key migration milestones and validate data continuity on the target system. At selected points throughout the migration, you will use <b>Joule for Consultants</b> with a dedicated <b>Migration Expert</b> to gain additional technical insights and support troubleshooting.</p><br>

## Requirements
To complete the exercises in this hands-on session, you need **SAP GUI** and a **web browser** (preferably **Google Chrome**).<br><br>

## Exercises
<p align="justify">Building on the <b>preconfigured landscape</b>, the exercises guide you through the migration, combining guided tasks in the <b>RISE with SAP System Transition Workbench</b> with manual activities in the SAP systems. Step by step, you will execute the migration, document key milestones, and validate the results on the target system.</p>

<p align="justify">Below you find an overview of all exercises included in this hands-on session:</p>

- [Getting Started: Scenario Overview & Hands-On Setup](exercises/ex0/)
- [Exercise 1 - Initiate the Transition: Check Prerequisites](exercises/ex1/)
- [Exercise 2 - Prepare the Transition: Download Software](exercises/ex2/)

- [Exercise 4 - Finalize the Tenant Copy](exercises/ex4/)
- [Exercise 5 - Complete Migration Post-Processing](exercises/ex5/)
- [Exercise 6 - Switch to the Main Instance](exercises/ex6/)
